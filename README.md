# 不要把这只猫带回家 · 简体中文补丁

适用于 **Do NOT Take This Cat Home PC 1.0**（本次测试引擎：Ren’Py 8.5.2.26010301）。这是非官方汉化补丁。原作、角色、美术、音乐及剧情属于 Pixeliminal 及各自权利人。

- [原作与官方下载](https://pixeliminal.itch.io/do-not-take-this-cat-home)
- [补丁下载](https://github.com/QianLieXian/DoNOTTakeThisCatHome-zhCN/releases/latest)

## 安装

1. 从作者页面下载并完整解压 `DoNOTTakeThisCatHome-1.0-pc.zip`，先退出游戏。
2. 备份游戏目录和存档；至少保留原来的两份英文 `.txt` 文档。
3. 下载 Releases 中的 `DoNOTTakeThisCatHome-PC1.0-zhCN-v1.1.0.zip`，把压缩包内的 **`game` 文件夹及其他文件直接复制到游戏根目录**。确认 `game` 与 `DoNOTTakeThisCatHome.exe` 同级，合并同名文件夹即可。
4. 正常运行原来的游戏程序。首次安装补丁默认进入简体中文。若已有语言偏好，在“设置”右下角点击“简体中文”；点击旁边的 `English` 可切回英语。

无需另装 Python、Ren’Py、字体或任何翻译软件。补丁使用原版内附的 `game/fonts/SourceHanSansCN-Regular.otf`。若缺少该文件，请重新取得对应的完整原版。

- 全部 **5,420 个剧情对白块**；剧情选项、角色称呼、菜单、设置、帮助、结局列表及系统提示，共 **6,354 项文本**。
- `Content_Warnings_Full_List.txt`：完整内容警告中文版。
- `Endings_guide.txt`：结局 0—39、小游戏提示及重置说明中文版，**含严重剧透**。
- 手机短信画面的中文覆盖层与“新消息”通知。v1.1.0 新增或重修 22 张带文字素材，包括镜子迷宫／电影院招牌、故障短信、ERROR 画面及结局图标，并兼顾追逐、黑白与淡出帧。
- v1.1.0 再次通读复核，修改 82 条去重译文，调整偏义、句子衔接、感叹强度及名称；两份文档同步统一用词。
- 中文字体与断行、未标记的主菜单标题，以及 `BACKUP` / `KILL IT` 谜题的中文语言兼容。

图片先通过内置 imagegen 修字，再限于文字及其擦除、描边范围合成；人物、主体背景和图标边框不作整图替换。原版图片文件保持原样，补丁只保存文字区域的像素差量，中文时载入、英文时恢复原图。运行时不下载内容，不依赖修图软件。

密码谜题仍按原版英文拼写，指南中已解释中文意思。字母按钮属于谜题本身，保留英文。

## 翻译方式与文风

由 Codex **独立阅读英文、逐句结合分支语境翻译，并自行复核**。没有调用在线翻译网站或批量翻译接口，也没有使用翻译子代理。此版本明确有 AI 参与，**不冒称真人手译或专业人工审校**。

保留日常自言自语逐渐转为恐怖、操纵与占有的语气变化；少量口语、粗口及双关按具体情境处理，不额外加入色情描写或与情节无关的梗。

## 卸载与存档

退出游戏后，移除补丁新增的 `game/tl/zh_CN` 文件夹，以及 `game/zz_zhcn_patch.rpy`、`game/zz_zhcn_phone.rpy`、`game/zz_zhcn_images.rpy`、`game/zhcn_image_deltas.json` 和对应同名 `.rpyc` 文件，即可移除游戏内汉化。两份根目录文档可用安装前备份恢复，或重新从作者页面取得。

补丁不附带存档、不解锁结局，也不修改原作剧情脚本。Windows 系统存档通常位于 `%APPDATA%\RenPy\DoNOTTakeThisCatHome-1675497927`，游戏目录下的 `game/saves` 也可能保存副本。**卸载汉化不需要删除这两个位置。**

本仓库不包含游戏程序、原版完整脚本、美术、音频、字体及个人存档；必须搭配作者发布的原版游戏使用。
